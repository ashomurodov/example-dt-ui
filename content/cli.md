# CLI Reference

The `dt-ui` CLI is a thin script around the registry. Every command is deterministic and idempotent — no surprise file rewrites, no global state.

## Commands

| Command | What it does |
|---------|--------------|
| `npx dt-ui init` | Initialize the registry in the current project. Writes `.dtui.json`, copies `base.css` and `lib/utils.ts`, creates `AGENT.md`. |
| `npx dt-ui list` | List every component in the registry with installed status. |
| `npx dt-ui add <name…>` | Copy one or more components into `src/components/ui/`. Resolves internal deps and installs npm peer deps. |
| `npx dt-ui update` | Refresh shared files (`base.css`, `lib/utils.ts`, `AGENT.md`). Optionally re-copies installed components — confirms before overwriting. |

## init

Run once at the start of a project. Asks a few questions about framework and target directories.

```bash
npx dt-ui init
```

After init you'll have `.dtui.json` at the root, `src/styles/base.css`, `src/styles/table-cells.css`, `src/lib/utils.ts`, and an `AGENT.md` file your AI assistant can read for full component reference.

## add

The most common command. Copies `.vue` + `index.ts` into your tree.

```bash
# Add several at once — internal deps auto-resolve
npx dt-ui add layout dialog button input

# Or pick interactively (no args)
npx dt-ui add
```

If a component declares an internal dep (e.g. `dialog` needs `button`), the CLI will ask before pulling it in. NPM peer dependencies (e.g. `reka-ui`) are installed automatically using your detected package manager.

## update

Use after upgrading `aetherx-dt-ui`. Updates the shared style file, the helper utilities, and the agent reference. Optionally re-copies installed components, but **always asks first** — local edits are sacred.

```bash
npx dt-ui update
```

## Config file

`.dtui.json` is generated by `init` and updated by `add`.

```json
{
  "framework": "vue-vite",
  "componentsDir": "src/components/ui",
  "libDir": "src/lib",
  "stylesDir": "src/styles",
  "installedComponents": ["button", "input", "card"],
  "agent": true
}
```

You normally don't edit this directly. The CLI mutates it as you add components.
